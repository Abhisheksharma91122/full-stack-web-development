# How the Web Works

## 1. How the Web Works (Simple Flow)
1. User enters a URL in the browser
2. Browser sends a request to a server
3. Server processes the request
4. Server sends a response
5. Browser displays the web page

---

## 2. Frontend
**Frontend** is the part of a website users see and interact with.

### Responsibilities
- Layout and design
- User interaction
- Displaying data

### Technologies
- HTML (structure)
- CSS (style)
- JavaScript (behavior)
- Frameworks: React, Angular, Vue

---

## 3. Backend
**Backend** runs on the server and handles logic and data.

### Responsibilities
- Business logic
- Database operations
- Authentication
- API handling

### Technologies
- Node.js, Python, Java, PHP
- Databases: MySQL, MongoDB, PostgreSQL

---

## 4. API (Application Programming Interface)
An **API** allows frontend and backend to communicate.

### How API Works
- Frontend sends a request
- Backend processes it
- Backend sends a response (usually JSON)

### Example
```json
{
  "name": "John",
  "email": "john@example.com"
}
