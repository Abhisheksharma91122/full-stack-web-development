# Internet Basics

## 1. What Is the Internet?
The **Internet** is a global network of interconnected computers and servers that communicate with each other using standardized protocols. It allows devices worldwide to share information and resources.

---

## 2. How the Internet Works
The internet works by breaking data into **packets** and sending them across networks.

Basic flow:
1. You request data (e.g., open a website)
2. The request is sent to a server
3. The server responds with data
4. Your device reassembles and displays the data

---

## 3. Key Internet Components

### 3.1 Devices
- Computers
- Smartphones
- Servers
- Routers
- Switches

### 3.2 Servers
Servers are powerful computers that:
- Store websites
- Process requests
- Send data to clients (users)

---

## 4. Internet Protocols

### 4.1 IP (Internet Protocol)
- Assigns a unique **IP address** to each device
- Example: `192.168.1.1` or `2001:db8::1`

### 4.2 TCP (Transmission Control Protocol)
- Ensures reliable data delivery
- Breaks data into packets and reassembles them

### 4.3 HTTP / HTTPS
- **HTTP**: HyperText Transfer Protocol
- **HTTPS**: Secure version with encryption
- Used for loading web pages

---
